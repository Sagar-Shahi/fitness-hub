Quick start

Replace YOUR_KEY with a key from above, and the address with your own site.

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/v1/workouts/ \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"date": "2026-11-12", "name": "Push day", "duration_min": 55, "exercises": [{"name": "Bench press", "sets": 4, "reps": 8, "weight_kg": "60"}]}'

curl -H "Authorization: Bearer YOUR_KEY" {{ request.scheme }}://{{ request.get_host }}/api/v1/summary/

# FitHub media sources

FitHub uses the following third-party media as optional visual assets. The site remains usable if a remote media host is unavailable.

## Landing-page and background fallback photo

- Photo: [Woman training with gym equipment and dumbbell](https://www.pexels.com/photo/woman-training-with-gym-equipment-and-dumbbell-6455896/)
- Creator: Julia Larson
- Source: Pexels
- Pexels marks this photo as free to use. The image is loaded from the Pexels image CDN; it is not bundled in this repository.

## Ambient background video

- Current background video source: [Pexels video 4921640](https://www.pexels.com/)
- The video is decorative, muted, and hidden for reduced-motion preferences. The photo poster and CSS background provide a fallback.

## Exercise catalogue

- [Free Exercise DB](https://github.com/yuhonas/free-exercise-db)
- License: Unlicense (public domain), as identified by the upstream project.
- Exercise images are loaded from the upstream GitHub raw-content host and cached exercise data is used where available.

## Gear Guide

Retailer product photos are not currently supplied by the seeded product records. FitHub intentionally displays a labelled placeholder rather than inventing a product image or implying that a generic gym photo depicts a specific item.
